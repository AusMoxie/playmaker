# Playmaker （https://wangxung815.github.io/playmaker/）

**Playmaker** is a lightweight but professional and comprehensive project management and budget planning tool designed for teams that need clarity without unnecessary complexity.

This tool was built from years of hands-on project management experience across multi-project environments. The goal is simple: help mid-sized teams plan work, manage capacity, track tasks, monitor budgets, and understand delivery risk in one practical workspace.

## Why Playmaker

Many popular tools are powerful, but they can also become heavy very quickly.

Microsoft Project is excellent for formal scheduling, but it can feel too complex for everyday team planning and budget conversations. Jira is strong for engineering workflows, but it often requires significant setup, maintenance, and process discipline before a broader team can use it comfortably.

Playmaker is designed for the space in between:

- More structured than a spreadsheet.
- Easier to use than enterprise project management systems.
- More budget-aware than a basic task board.
- More practical for multi-project resource planning than a simple to-do app.

It focuses on the day-to-day questions project leaders and teams actually need to answer:

- What are we working on?
- Who is assigned?
- How much capacity do we have?
- Where are the budget and effort risks?
- Which tasks are blocked, pending, or falling behind?
- How do multiple projects compete for the same people?

## Key Features

- **Multi-project planning** for managing several workstreams in one place.
- **Task board and timeline views** for planning work by sprint, target date, status, and group.
- **Team view** for understanding what each person is working on across projects.
- **Capacity planning** to compare assignments against weekly capacity.
- **Budget and allocation tracking** for project-level planning and resource usage.
- **Dashboard and timeline reporting** to make status, risk, and workload easier to understand.
- **Local file based workflow** so users can keep ownership of their own project data.
- **Simple user experience** designed to be approachable for non-technical users.

## Designed For

Playmaker is especially useful for:

- Mid-sized teams.
- Project managers handling multiple projects at the same time.
- Teams that need both task tracking and budget awareness.
- Resource managers who need a clearer picture of capacity and workload.
- Business teams that find Jira too engineering-focused.
- Teams that find Microsoft Project too heavy for day-to-day collaboration.

## Local Data Ownership

Playmaker is designed around local project files. Users can open and save their own JSON plan files, and they can sync those files using their preferred file sync service such as iCloud Drive, OneDrive, Dropbox, or Google Drive desktop sync.

The hosted web app provides the interface. Your project data remains in the files you choose to open and manage.

For the best experience, use a modern Chromium-based browser such as Chrome or Edge, especially when working with local file open/save features.
